# 🚀 Portfolio Template - Professional Websites in Minutes

**Build beautiful, bilingual portfolio websites in 5 minutes!**

This is a complete portfolio template system that makes it easy to create professional portfolio websites for yourself or clients. Everything is modular, customizable, and ready to deploy.

---

## ⚡ Quick Start

### 1. Automatic (Recommended)

```bash
./generate-portfolio.sh
```

Prompts for: name, email, phone, LinkedIn, brand color → Complete portfolio generated!

### 2. Manual

```bash
cp -r portfolio-template my-portfolio
cd my-portfolio
nano config.js  # Edit content
python3 -m http.server 8080  # Test
```
