# Client Onboarding Flow

Complete workflow van eerste contact tot live website, met design approval gates.

---

## 🎯 Overzicht

```
Lead → Intake → Betaling → Design Approval → Development → Review → Go-Live → Training
```

**Tijdlijn per package:**
- Quick Start: 1-2 weken (5-10 werkdagen)
- All-In: 3-4 weken (15-20 werkdagen)
- Premium: 6-8 weken (30-40 werkdagen)

---

## 📋 Fase 1: Lead & Discovery (Dag 0-1)

### Lead komt binnen via:
- Website contact formulier
- WhatsApp direct contact
- LinkedIn/sociale media
- Referral van bestaande klant

### Eerste contact (binnen 24 uur):
**Email/WhatsApp template:**
```
Hey [Naam]! 👋

Thanks voor je interesse in een professionele website!

Ik help [professionals/atleten/etc.] met websites die écht klanten aantrekken.

Voordat we aan de slag gaan, heb ik wat info nodig.
Kan je deze intake checklist invullen? (5 min)

→ [Link naar intake formulier]

Zodra ik dit heb, plan ik een gratis kennismaking in (30 min).

Vragen? Stuur gerust een berichtje!

Groet,
Nathalja
```

**Actie:**
- [ ] Stuur intake formulier (zie INTAKE-CHECKLIST.md)
- [ ] Plan kennismakingsgesprek (Calendly link)
- [ ] Stuur pricing sheet (packages overview)

## 📋 Fase 2: Intake & Scoping (Dag 1-2)

### 30-min Kennismakingsgesprek (Zoom/Google Meet)

**Agenda:**
1. **Introductie** (5 min)
   - Wie ben ik, wat doe ik
   - Mijn aanpak: design eerst, dan bouwen

2. **Hun verhaal** (10 min)
   - Wat doe je? Wie is je doelgroep?
   - Wat is je doel met de website? (leads, zichtbaarheid, geloofwaardigheid)
   - Hebben ze al een website? (migratie of vanaf nul)

3. **Package selectie** (10 min)
   - Lopen door packages (Quick Start, All-In, Premium)
   - Scoping: hoeveel pagina's, welke features
   - Localization: welke talen? (NL/EN/anders)

4. **Design voorkeuren** (5 min)
   - Laat voorbeelden zien (template variants)
   - Welke stijl spreekt aan? (professional, dynamic, etc.)
   - Kleuren, branding, sfeer

**Na gesprek:**
- [ ] Stuur offerte/voorstel (email)
- [ ] Betaallink (eerste termijn)
- [ ] Project timeline (verwachte oplevering)


## 💳 Fase 3: Betaling & Kickoff (Dag 2-3)

**Automatische email:**
```

We gaan aan de slag met jouw website!

Volgende stappen:

2. Over 3-5 werkdagen krijg je de eerste design concepts
3. We reviewen samen, jij geeft feedback
4. Na approval: ik bouw de website

Timeline: oplevering verwacht op [datum]

In de tussentijd: verzamel alvast je content (logo, foto's, teksten).
Ik stuur vandaag nog de gedetailleerde checklist.

Let's go! 🚀
Nathalja
```

**Acties:**
- [ ] Maak project aan in dashboard (status: "Content Gathering")
- [ ] Stuur content checklist (zie hieronder)
- [ ] Setup project folder (Google Drive/Notion)
- [ ] Plan design kickoff (intern)

### Content Checklist

**Email naar klant:**
```
Content Checklist - [Project naam]

Upload je content via deze link: [Google Drive/Portal link]

□ Logo
  - Formaat: PNG/SVG met transparante achtergrond
  - Kleuren: Primaire brand kleur (hex code)

□ Foto's
  - Headshot/profielfoto (high res, minimaal 1000px)
  - [Voor professionals]: Foto's van jezelf, team, kantoor, etc.
  - [Voor atleten]: Actiefotos, wedstrijden, prestaties
  - Minimaal 5-10 foto's, liefst professioneel

□ Teksten (per pagina)
  - Homepage: Hero tekst, intro, wat doe je?
  - About: Jouw verhaal, expertise, ervaring
  - [Services/Prestaties]: Wat bied je aan / wat heb je bereikt
  - Testimonials: 3-5 quotes van klanten/partners
  - Contact: Email, telefoon, sociale media links

□ Social Proof
  - LinkedIn profiel URL
  - Instagram/andere social media
  - Certificaten, awards, publicaties
  - Klanten/partners logo's (optioneel)

□ SEO
  - Keywords waar je op gevonden wil worden (5-10 stuks)
  - Meta description (1-2 zinnen over jezelf)

Deadline: [X] dagen

Vragen? Laat maar weten!
```

## 🎨 Fase 4: Design Concepts (Dag 3-7)

### Design Process

**Stap 1: Wireframes/Mockups maken**
- Gebruik Figma/Canva/andere tool
- Maak 2-3 homepage varianten (A/B/C)
- Design key pages (About, Services/Prestaties, Contact)
- Mobile + Desktop views

**Stap 2: Design Presentation aan klant**

**Email:**
```
Je website design is klaar! 🎨

Ik heb [2-3] design concepts gemaakt. Check ze hier:
→ [Figma link / PDF]

Wat vind je ervan?
- Welke variant spreekt je het meest aan?
- Kleuren goed? Of aanpassen?
- Teksten/foto's goed geplaatst?

We plannen een kort review call (15-30 min) om door te lopen.
Kies een moment: [Calendly link]

Of geef via email/WhatsApp feedback - wat jij makkelijk vindt!

PS: We doen zoveel revisie rondes als nodig tot je 100% tevreden bent.
```

### Design Review Call (15-30 min)

**Agenda:**
1. Walkthrough designs (screen share)
2. Feedback verzamelen
3. Prioriteren: must-changes vs nice-to-haves
4. Akkoord of nieuwe ronde?

**Notities maken:**
- [ ] Wijzigingen kleuren
- [ ] Tekst aanpassingen
- [ ] Layout wijzigingen
- [ ] Extra secties/pagina's

**Revisie rondes:**
- Quick Start: Max 2 rondes
- All-In: Onbeperkt (binnen 4 weken)
- Premium: Onbeperkt (binnen 8 weken)

## 🔍 Fase 7: Review & Revisions (Dag 20-25)

### Review Process

**Review Call (30 min)**
- Screen share door website
- Klant wijst op aanpassingen
- Noteer alles, prioriteer

**Categorieën:**
1. **Critical** (moet voor go-live): Spelfouten, broken links, verkeerde info
2. **Important** (snel fixen): Design tweaks, content wijzigingen
3. **Nice-to-have** (post-launch): Extra features, optimalisaties

**Revisie rondes:**
- Fix critical + important
- Release nieuwe staging versie
- Nieuwe review
- Repeat tot klant tevreden

**Final Approval:**

**Email:**
```
Website review - Final Check ✅

Alle wijzigingen doorgevoerd!

Final check voordat we live gaan:
→ [staging link]

Als alles goed is, stuur ik de factuur voor de 2e termijn (50%).
Na betaling zetten we de site live op je eigen domein.

Klaar om live te gaan? 🚀
```

- Waar zie je hoeveel bezoekers?

**3. Maintenance & Updates**

**4. Support & Next Steps**

## 🚨 Red Flags & Escalatie

### Wanneer project in gevaar:

**Red Flags:**
- Klant reageert niet op emails (>5 dagen)
- Design feedback blijft onduidelijk (>3 rondes zonder approval)
- Scope creep (klant vraagt steeds meer features)
- Betaling 2e termijn niet ontvangen

**Escalatie protocol:**
1. Friendly reminder (email/WhatsApp)
2. Phone call (persoonlijk contact)
3. Timeline adjustment (nieuwe deadline afspreken)
4. Last resort: project on-hold (bij non-payment)

**Email template (non-responsive klant):**
```
Hey [Naam],

Ik heb je een paar keer gemaild over [design feedback/content/etc.].

Ik wil graag verder met je project, maar heb jouw input nodig!

Kunnen we even bellen deze week? Ik wil je website op tijd opleveren.

Laat me weten wat je past!

Groet,
Nathalja
```
